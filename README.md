## Projetos em Destaque

### 🏥 Supply Chain — Dashboard Hospitalar
Pipeline de análise de dados focado em supply chain hospitalar. Análise de fornecedores, estoque, logística e desempenho operacional com KPIs de giro de estoque, ciclo de cotação e performance de compras.

**Stack:** Python · Pandas · Streamlit · Plotly  
[![Repositório](https://img.shields.io/badge/Ver_repositório-181717?style=flat-square&logo=github)](https://github.com/arnaldweger/Supply_Chain)

---

### 💰 BancoERP — Conciliação Bancária
Aplicação de conciliação entre extratos bancários e lançamentos no ERP Tasy. Interface interativa em Streamlit com suporte a arquivos CSV (Safra) e XLSX (Tasy), com validação cruzada e relatórios gerenciais.

**Stack:** Python · Pandas · Streamlit · OpenPyXL

---

### 📊 Análise de Fundamentos — Mercado de Ações BR
Pipeline completo de screening de ações brasileiras usando indicadores fundamentalistas (P/VP, PSR, ROIC, ROE, EV/EBITDA). Sistema de scoring ponderado por quartil com metodologia de Information Value (IV) e Weight of Evidence (WoE).

**Stack:** Python · Pandas · Jupyter · Matplotlib · Plotly

---

### 🤖 Sistema Helferweg — IA de Gestão
Sistema multi-agente local com arquitetura modular baseada em Ollama. Agentes especializados em análise, direção, organização, programação e pesquisa web (DuckDuckGo). Focado em automação de processos de gestão.

**Stack:** Python · Ollama · llama3.1 · DuckDuckGo API

---

### 📧 Follow-up Automatizado — Fornecedores
Automação de rastreamento de ordens de compra e comunicação com fornecedores via Outlook/SMTP. Inclui pipeline de controle de status, geração de e-mails personalizados e alertas por prazo.

**Stack:** Python · smtplib · Pandas · Selenium

---

### 🃏 Geração de Dados Fictícios — Cartão de Crédito
Gerador de datasets sintéticos para testes e validação de pipelines financeiros. Útil para simulações de transações sem expor dados reais.

**Stack:** Python · Faker  
[![Repositório](https://img.shields.io/badge/Ver_repositório-181717?style=flat-square&logo=github)](https://github.com/arnaldweger/GerandoDadosCartao)
